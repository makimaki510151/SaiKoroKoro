# サイコロコロ

盤面のダイスをグリッドに沿って転がし、ゴールのマスで上面をすべて 1 にするステージ制パズルです。

## 遊び方

- ダイスをタップして選ぶ（最初は全部選択）
- 方向ボタン、スワイプ、矢印キー / WASD で、選んだダイスを同じ方向へ転がす
- 複数同時に転がしても手数は 1。別方向へ同時には転がせない
- 地面のないマスへ転がすと落下して失敗
- 制限手数で揃えられないと失敗。戻すで 1 手返せる
- 同じ方向に 2 回転がすと、上面は最初の裏面になる

## レベルデザイン

地面、ゴール、ダイスの初期配置、制限手数を編集できます。出力できるのは、その初期配置からテストプレイで実際にクリアしたステージだけです。クリアできない配置は出力できません。

## 起動

```bash
npm install
npm test
npm run dev
```

ブラウザで表示された URL を開きます。`npm run build` で `dist/` に静的ファイルを出力します。
